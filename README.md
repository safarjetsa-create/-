## 🌟 نظرة عامة على المشروع (Project Overview)

منصة **سفرجيت (SafarJet)** هي منظومة سياحية وتقنية متطورة تجمع بين واجهة عملاء فاخرة وعصرية تليق بالمسافرين المميزين في المملكة العربية السعودية والخليج العربي، وبين لوحة تحكم وغرفة عمليات مركزية متقدمة (Operations Command Center & CRM Pipeline) تمكّن وكالة السفر من متابعة الحجوزات، توليد عروض الأسعار، وتخصيص البرامج السياحية بضغطة زر.

---

## ✨ المميزات الرئيسية للمنصة (Key Features)

### 1. بوابة المسافر وتجربة العميل (Public Client Portal)
* **محرك البحث الذكي (Multi-Tab Booking Engine):** بحث فوري مخصص لحجوزات الطيران، الفنادق الفاخرة، الباقات السياحية، وخدمات النقل والمواصلات الخاصة.
* **شبكة 12 خدمة سياحية متخصصة:**
  * 🕋 باقات العمرة الملكية VIP (فنادق صف أول مطلة على الكعبة المشرفة وقطار الحرمين).
  * 🛩️ استئجار الطائرات الخاصة وطائرات رجال الأعمال (Private Jets & Concierge).
  * 🏝️ باقات شهر العسل الفاخرة والفلل المائية (المالديف، بالي، سيشل).
  * 🌲 العطلات العائلية الأوروبية الشاملة (البوسنة، سويسرا، النمسا).
  * 🚢 رحلات الكروز البحرية واليخوت الفاخرة.
  * 🏥 السياحة العلاجية والتعليمية مع كبرى المراكز العالمية.
* **مسار الحجز الذكي المتدرج (Smart Booking Funnel):** تجربة حجز انسيابية تجمع تفضيلات العميل خطوة بخطوة وتربطها بغرفة العمليات والواتساب.
* **دليل الباقات وخط السير يوماً بيوم (Day-by-Day Itineraries):** استعراض مفصل لكل يوم في الرحلة، الفنادق المشمولة، وقوائم المشمولات وغير المشمولات (Inclusions & Exclusions).
* **مستشار السفر الذكي (24/7 AI Concierge):** شات بوت تفاعلي مدعوم بالذكاء الاصطناعي يرشد العملاء ويجيب عن استفسارات الوجهات فورياً.
* **بوابة وحساب المسافر VIP (Customer Profile):** استعراض الرحلات القادمة، رصيد نقاط النخبة (VIP Gold)، ومتابعة عروض الأسعار.
* **وثيقة السفر وتصريح الصالة الإلكتروني (VIP Boarding Pass & Lounge Access):** تذكرة صعود فاخرة مجهزة بـ QR Code وباركود أمني صالحة للطباعة المباشرة وحفظها كملف PDF.
* **الصفحات القانونية والاعتمادات:** سياسة الخصوصية وسرية البيانات (مطابقة لنظام PDPL السعودي)، الشروط والأحكام وسياسات الإلغاء، ومركز الأسئلة الشائعة (FAQ).

---

### 2. غرفة العمليات ولوحة التحكم المركزية (SafarJet Admin OS)
* **تصميم ذكي متكيف بالكامل (Full-Width Adaptive Command Center):** واجهة عريضة تستغل 100% من مساحة الشاشة без أي فراغات أو هوامش ميتة على الشاشات العريضة و1080p و2K و4K.
* **نظام التنبيهات الصوتية الحية (Harmonic Luxury Chimes):** تنبيه صوتي فوري عند وصول أي حجز VIP جديد مع نافذة إشعار تفاعلية منبثقة.
* **مسار متابعة المبيعات والطلبات (5-Stage CRM Kanban Board):**
  * 📥 طلبات جديدة (New Leads).
  * 📞 جاري التواصل (Contacted).
  * 📑 تم إرسال العرض (Quoted).
  * 💳 تم تأكيد الحجز (Booked).
  * ✅ رحلات مكتملة (Completed).
* **شريط بحث وفلترة لحظي:** بحث بالاسم، رقم الجوال، أو نوع الوجهة والرحلة.
* **تصدير البيانات إلى Excel (CSV Export):** تصدير سجلات العملاء والطلبات بترميز `UTF-8 with BOM` سليم يفتح بالعربية المنسقة في Microsoft Excel بنقرة واحدة.
* **مولد عروض الأسعار الرسمية (VIP PDF Quotation Generator):** إصدار عروض أسعار بتنسيق رسمي راقٍ قابل للطباعة والحفظ الفوري.
* **باني البرامج والباقات السياحية (Visual Package Builder):** إضافة برامج سياحية جديدة، إدراج صور الوجهات، وتحديد جدول الأيام التفصيلي ونشرها للموقع مباشرة.
* **خادم الواتساب التلقائي ومراقبة الذكاء الاصطناعي (WhatsApp Engine & AI Takeover):** محاكاة اتصال السوكيت الفوري وتفعيل أو تعليق التدخل البشري للموظفين.

## 🛠️ البنية التقنية (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Next.js 14 (App Router)** | إطار العمل الأساسي للواجهات والـ Server-Side Rendering والـ Static Generation |
| **React 18** | مكتبة بناء واجهات المستخدم التفاعلية |
| **TypeScript** | الأمان البرمجي وتدقيق الأنواع والبيانات الصارم |
| **Tailwind CSS** | بناء التصاميم العصرية وتنسيق الهوية البصرية ونظام الـ Glassmorphism |
| **Lucide React** | حزمة الأيقونات الفكتوريا التفاعلية |
| **Web Audio API** | هندسة النغمات الصوتية التنبيهية الفاخرة للوحة التحكم |
| **Next.js API Routes** | نقاط الاتصال البرمجية الداخلية (`/api/inquiries`, `/api/packages`) |

## 🚀 تشغيل المشروع محلياً (Getting Started)

### 1. تثبيت الحزم والتبعيات (Install Dependencies):
```bash
npm install
```

### 2. تشغيل خادم التطوير (Run Development Server):
```bash
# تشغيل الخادم على المنفذ الافتراضي:
npm run dev

# أو تشغيل الخادم على منفذ مخصص (مثل 3005):
npm run dev -- -p 3005
```

افتح المتصفح على:
* **البوابة العامة:** [http://localhost:3005](http://localhost:3005)
* **غرفة العمليات المركزية:** [http://localhost:3005/admin](http://localhost:3005/admin)
* **بوابة المسافر VIP:** [http://localhost:3005/profile](http://localhost:3005/profile)

### 3. بناء واختبار نسخة الإنتاج (Production Build):
```bash
npm run build
npm run start -- -p 3005
```
